# 常见问题

## 启用后为什么仍显示原界面？

先通过“文件 → 退出”完全退出 Codex，再点击桌面或开始菜单入口。关闭窗口的“×”通常保留后台进程，不能应用新的启动环境。商店、旧任务栏固定入口、系统协议等入口可能绕过主题；从已接管的桌面入口重新固定到任务栏。

## 开场会不会每次唤回窗口都播放？

不会。已有后台实例时恢复原窗口和主题；完全退出后的启动才播放开场。启动接入失败会恢复窗口显示，某些版本下可能短暂露出原生启动页。

## 恢复默认会不会删除聊天或退出登录？

不会。恢复只停用本项目、清理可验证的活动主题并恢复原快捷方式。不会删除独立界面配置、登录、聊天、项目、插件或个人偏好。若已有后台任务，完成后完全退出并重新打开，结束该实例中的主题环境。

## 能否移动目录、同时安装多个副本？

保留一个安装目录。移动前先运行旧目录的恢复脚本，再移动并重新启用。切换安装位置时备份会保留；不要同时运行多个安装副本。恢复拒绝覆盖安装后被其他程序修改的快捷方式，需要先检查报错及备份记录。

## 是否需要管理员权限或额外下载？

不需要管理员权限。需要已安装的 Store 版 Codex 和可信 Node.js 22+；不会随包附带数百 MB 的完整应用或 Node 运行时。源码版首次启用可自动编译小型启动程序。Windows 使用包已经编译，不需要开发工具。

## Windows 拦截脚本或程序怎么办？

下载来源应当可信；检查 SHA256SUMS.txt，并完整解压。入口脚本只对本次执行使用 PowerShell 执行策略，不修改全局策略；运行时会解除本包 PowerShell 辅助脚本的下载标记。程序未做代码签名，Windows 可能显示来源提示。受组织策略限制时请遵循设备管理员配置。

## 首次聊天反复重连怎么办？

如果正在使用本机代理，在设置中打开“网络兼容”，完全退出 Codex 后重新打开。它沿用 Windows 已启用的固定本机 HTTP 代理；不提供代理服务，不处理 PAC 或远端代理，不覆盖已有代理环境。没有本机代理时保持关闭。一般网络故障或服务故障仍可能导致重连。

## 更换素材或调整颜色在哪里操作？

在设置窗口选择本机素材，关闭窗口保存。使用包的命令是 `app/ConanLauncher.exe --settings`；源码版使用根目录 EXE。推荐原生外观选择深色。暂停壁纸仅临时停止注入，完整恢复请使用顶层“恢复默认”。

## Codex 更新后主题失效？

本项目依赖非官方本地界面接入，不能保证适配所有版本。运行恢复脚本并使用原应用；报告问题时附 Codex 版本、项目版本、现象和已脱敏错误，不上传账号文件、完整用户配置或聊天日志。
